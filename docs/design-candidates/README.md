# Design candidates · drop zone

Candidates from the Claude Design track land here for verdict against the briefs in
../design-briefs/. Convention:

- `candidate-website-v1.html` / `candidate-personas-v1.html` / `candidate-calendar-v1.html`
- screenshots as `candidate-website-v1.png` (and mobile as `-mobile.png`)
- the tool's own deviation notes as `candidate-website-v1-notes.md`, pasted verbatim

Verdict process (site session): render + view, check against the brief's locked laws
(palette, type, accent dosage, imagery law, no-spoiler where applicable), then a
keep / salvage-parts / reject note per candidate, logged in SITE-PLAN's register.
Nothing is adopted into mocks without a register entry. Per the standing order, all of
it is concept-test material until the two-way review with the book.
