THE CASE FILE · READER'S MAP

One project, walkable

The book is the argument; this file is the record it argues from. Ostermill is a designed composite: no real company, no real people, every number derived from one internally consistent canon. Sixteen weeks from a Friday demo to production, then governance that never ends. Five phases, each with its meetings, its paperwork, and its evidence. Start anywhere; every surface links back here.
